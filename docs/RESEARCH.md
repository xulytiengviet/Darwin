# Darwin EvoDNA — Five-niche research specification (v0.1)

> Status: **hypothesis and reproducible toy simulators**, not evidence of a self-generating LLM, biological xenobot control, or successful speech-to-meaning encoding.

## Core proposition

Can a seed produced by **natural speech → digital acoustic features** (or by **ASR → Unicode → audited CVNSS4.0 conversion**) be transformed into an evolvable computational genotype built from 27 symbols, each corresponding to three balanced trits, and thereby improve development of programs, protocols and agents under objective evaluation?

This is a **falsifiable hypothesis**, not a theorem. A hash-based initialization may be scientifically indistinguishable from a random seed; finding that it offers no benefit is a valid negative result.

### Signal vs text vs semantics

- Raw PCM, sampled at F_s: x[n], a numerical representation of acoustic pressure.
- Frame-level spectral features: e.g., log-Mel, speech embeddings or discrete neural codec units. The prototype uses 27 Goertzel frequency probes per segment, **not a learned speech codec**.
- Digital symbolization: q: feature → {0,...,26}, intentionally **lossy**.
- Text path: Unicode → local CVNSS4.0 v5.0.0-audit-safe converter → symbolic hash → genome (**implemented**).\n- Speech-to-text bridge: ASR(audio) → Unicode → converter (**not implemented**, external ASR needed).
- Seed key: deterministic initialization value; **not a secret key**; a hash neither preserves syntax nor semantic content.
- Genome: structured symbols interpreted by a developmental compiler into executable components and learning rules.
- Phenotype: program/agent/protocol/model generated by that compiler; performance is defined by a task and held-out evaluator.

A 27-state symbol can represent log2(27) ≈ 4.755 bits of information in the ideal equiprobable case; 3 balanced trits × log2(3) is the same entropy capacity. This does not imply improved storage or physical ternary hardware performance. Base27 text glyphs are not identical to physical trits.

One consistent mapping:
i ∈ {0,..,26}, v=i−13; v=9t₂+3t₁+t₀ with each t∈{−1,0,+1}.
The mapping is a bijection. It supplies **representation**, not a generative model.

## Research niche 1 — Evolutionary computation & artificial life

- Question RQ1: Does constrained Base27 ternary genotype evolution outperform random or binary representation under identical evaluation budgets?
- Basic pipeline: seed → initial population → crossover/mutation → score → selection → archive → next generation.
- Current code: artificial local-pattern fitness with weighted neighboring consistency (toy only).
- Proposed next simulator: energy-limited 2D artificial cells that perceive resource maps, consume energy to move, and can reproduce conditionally. Keep rules explicit; no biological claims.
- Fitness beyond toy: survival under unseen resource configurations, multiobjective Pareto diversity, regret under disturbances, energy-cost-adjusted reward.
- Controls: random search, hill climb, GA, NEAT-like topology evolution, MAP-Elites; equal evaluation calls.
- Failure diagnostics: loss of diversity, deceptive reward, local optima, neutral drift and bloat.
- Falsification: no improvement on unseen environments or benefit attributable solely to seed labels.

## Research niche 2 — AI for Science & xenobot-inspired research

- Question RQ2: Can sample-efficient surrogate-guided evolution prioritize **in-silico** shapes in a high-cost evaluator setting?
- Current code: **abstract symmetry + target matching**; intentionally no cells, biomechanics or flow simulation.
- Planned trusted extension: validated numerical dynamics from existing literature; use simulator uncertainty and out-of-distribution detector; if an authorized scientific collaborator supplies independent reference data, test simulation-to-observation error.
- Hierarchical control: language specifies *goal and constraints*, never a direct, unvalidated causal command to living tissue.
- Evolution loop: proposal → cheap surrogate filter → expensive verified evaluator → updated uncertainty → candidate archive.
- Comparators: random search, Bayesian optimization, quality-diversity, active learning and evolution strategies at matched expensive-evaluation budgets.
- Decision gates: independent physical validation, multidisciplinary review, biosafety and ethical authorization before any real biological study.
- **Do not infer** xenobot steering, autonomous replication safety, therapeutic value, or actual life from browser outputs.

Reference: Blackiston et al. (2021), *A cellular platform for the development of synthetic living machines*, Science Robotics, https://doi.org/10.1126/scirobotics.abf1571 ; https://wyss.harvard.edu/news/team-builds-first-living-robots-that-can-reproduce/ .

## Research niche 3 — Open-endedness, continual learning & LLM-guided search

- Question RQ3: Can an external LLM *propose* symbolic genome / program variants that improve held-out objectives more efficiently than mutation alone, given cost and safety?
- Current code: two related synthetic objectives, changes every shift interval; **no LLM integration**.
- Future architecture: LLM proposal service (server-side auth), typed AST patch gate, static analysis, resource-limited sandbox, test evaluator, novelty archive, rollback.
- Prevent reward hacking: use hidden evaluator tests, independently developed test suite, multiple tasks and audit logs.
- Continual learning: versioned replay buffer with real environment feedback; measure forgetting on prior tasks.
- Open-endedness cannot be inferred from novelty alone; measure creation and reuse of qualitatively new skills across increasing task complexity.
- Negative condition: gains disappear after matching total candidate evaluations or tokens.

References: AlphaEvolve https://arxiv.org/abs/2506.13131 ; Darwin Gödel Machine https://arxiv.org/abs/2505.22954 ; FunSearch https://www.nature.com/articles/s41586-023-06924-6 .

## Research niche 4 — Cultural evolution & social learning

- Question RQ4: Will agents evolve transferable protocols using a limited symbol inventory when communication helps perform grounded tasks?
- Current code: simple codebook uniqueness proxy and target agreement, **not** real multi-agent communication.
- Proposed experiment: sender sees an object, receiver acts in hidden maze / referential game, only Base27 messages pass between them. Evaluate success, message length, compositionality, new-agent transfer, out-of-distribution referents.
- Compare direct acoustic seed against text seed against random seed; do not equate token agreement with shared meaning.
- Model collapse controls: protect human/environment-origin samples, quantify distributional coverage and rare-event retention, never use model-generated outputs as sole ground truth.
- Failure condition: high training communication success with low generalization to unseen partners or objects.

References: *A framework for the emergence and analysis of language in social learning agents*, Nature Communications (2024), https://www.nature.com/articles/s41467-024-51887-5 ; *AI models collapse when trained on recursively generated data*, Nature (2024), https://www.nature.com/articles/s41586-024-07566-y .

## Research niche 5 — Universal evolutionary reasoning

- Question RQ5: How should a population optimizer reason under changing distributions, expensive evaluations and self-deceptive feedback?
- Current code: shifting synthetic targets plus robustness to adjacent target.
- Planned environment: concept drift, latent adversarial shifts, oracle costs and diversity archive; quantify regret, adaptation delay and worst-case fitness.
- Reasoning principles: population over single best; preserve counterfactual candidates; favor falsifiable external tests; value uncertainty estimates; account for cost per evaluation.
- Check for Goodhart: trained score improves but independent, hidden outcome worsens.
- Out-of-sample audit: benchmark hold-out, external evaluator, blinded scenario definitions and ablation experiments.

## Four-tier scientific claim taxonomy

1. Mathematical identity: 27=3³ and Base27↔3 balanced trits — **provable**.
2. Software capability: deterministic browser simulation & seed inheritance — **unit-testable**.
3. Simulation result: improvement against a toy objective — **conditional on task assumptions**.
4. Scientific generalization: self-generating LLM, grounded language, xenobot control, more efficient AI — **not demonstrated**.

## Reproducibility protocol

1. Pre-register task family, fitness formula, budgets, population size, mutation policy, drift schedule and seeds.
2. Preserve raw task generation settings and independent hold-out evaluator.
3. Run ≥20–30 independent random seeds per condition when computationally viable; report mean/median, uncertainty interval and full distributions.
4. Compare equal wall-clock, compute, API tokens and external evaluator calls, not just generation counts.
5. Run ablations: random Base27 vs text hash vs audited CVNSS4.0; audio token vs text; binary vs ternary; evolution vs no evolution; with vs without diversity selection.
6. Store machine-readable JSON reports, checkpoint hashes, software versions and failure cases.
7. Publish results and limitations. Do not interpret synthetic simulation projections as empirical forecasts.

## Code limitations and next engineering upgrades

- Base engine currently uses a fixed length-24 genome, 36-population default, and a conventional selection/crossover/mutation search.
- Seed initialization uses 70% seed-descendant candidates and 30% random individuals.
- Hold-out is a perturbation of the same synthetic target and is **not an independent real dataset**.
- Forecast is a repeated-run 10–90 percentile band, **not** predictive confidence about scientific outcomes.
- Audio fingerprint is fixed-window dominant-frequency quantization; different pronunciations of the same words can yield different seeds, while different utterances can collide. Measure token stability and collision rate before using downstream.
- Experimental next steps: MAP-Elites archive; explicit generational task transfer; benchmark true multi-agent coordination; LLM proposal adapter with backend safety controls; converter regression/audit harness; actual spectrogram/vocoder comparisons; separate simulator-validation study.
